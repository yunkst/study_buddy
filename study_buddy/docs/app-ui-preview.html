重设计要点

三 Tab 职责单一：今日 = 学什么，知识 = 沉淀与背诵，设置 = 系统归拢。打开 App 第一屏零滚动触达学习闭环。

今日 · 学习中枢
「问 AI」单个导航行取代了原三按钮（拍照 / 相册 / 直接聊），点击进全屏对话页（/ai）；今日计划摘要、开始专注、学习日报、今日待复习 仍为设置行。复习入口按 dueNowCountProvider 显示张数，0 张自动置灰。
知识 · 沉淀背诵
分类树下钻 + 搜索（TopicRepository.search）。行内显示掌握度徽标（从 FSRS 稳定性 S 派生）+ 下次复习时间。点进详情页。
设置 · 系统归拢（本次重设计）
改为分组设置行：外观（主题模式）/ 系统（LLM 配置 · 版本更新 · 关于）/ 诊断（日志）。LLM 配置收敛为入口行，点按弹底部表单，不再首屏铺表单。
底部 Sheet 交互
LLM 配置、主题模式均为 showModalBottomSheet：点击设置行弹出，点遮罩关闭。右侧手机可点试。
知识点详情页

从知识 Tab 或聊天里的知识点卡片点进。面包屑 → 标题 → 掌握度 → 引子 → 答案（公式）→ 关联 → 掌握度轨迹 + 底部三操作。

入口合并

今日页只留一个「问 AI」导航行，context.push('/ai') 进入全屏对话页。拍照 / 相册 / 直接聊三个入口移入对话页空态引导（避免首页三按钮太奇怪）。

聊天中加图

输入行左侧「加图」按钮（Icons.add_photo_alternate_outlined）→ 弹 chooser → 选拍照 / 相册 → pickImageForAi → 推 /crop 框选 → 设为待附图缩略（带移除按钮）。

会话保留

会话状态在全局 currentChatProvider（StateNotifierProvider），页面 dispose 不触发 clear。返回今日页后再进入，聊天历史仍在（历史上非空时输入框提示「追问…」、按钮「发送」）。

其他入口

分享冷启动（app.dart）和知识点详情页深度交流（topic_detail_page）也走同一全屏页（showAiPanel 签名不变，内部统一改为 push）。

公式渲染 / 知识点卡片

同前：AI 回复用 Markdown + LaTeX；save_topic 渲染为可点击卡片，新 → 朱砂「新」，已存在 → 掌握度标签。
