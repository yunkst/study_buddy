背诵怎么工作 — 抽认卡翻面
每个知识点天然是一张卡：正面是 question（背诵引子），背面是 summary（答案本体）。背诵模式按掌握度筛选（薄弱、学习中的优先），先看正面回忆，点翻面看答案，再自评标记掌握度——背会的标「已掌握」，不会的留「薄弱」继续轮。标记写入 MasteryLog，形成复习闭环。数据全部来自 engine 已有的 Topic / MasteryStatus，无需建表。

技术改动范围
