背诵怎么工作 — 间隔重复（FSRS）
艾宾浩斯遗忘曲线是连续的，几个静态掌握度标签画不出它。所以每个知识点背后挂一份记忆调度：稳定性 S（多久忘一半）、下次复习 due、复习次数与失误数。复习时四档自评更新 S 与 due——系统在该复习时把你叫回来，平时不打扰。每日队列有上限，多了顺延，不会雪崩。掌握度标签（薄弱/学习中/已掌握）从 S 派生展示，仍可手动覆盖。Anki 验证过的成熟范式，且复习全程离线、零 LLM 成本。

今日队列从哪来

topic_schedule 表里 due_at ≤ 今日 的知识点。新建知识点首日 due = 当日（进队），之后每次评分重算。

优先级排序

越逾期 + 稳定性 S 越低越靠前——最该抢救的先复习。每日上限（默认 20）截断，余下顺延（S 继续衰减，明天更优先，不会堆成山）。

四档评分 → FSRS

忘了：due 置零、失误数 +1；困难/良好/简单：稳定性 S 按系数增长、难度 D 调整，重算 due。按钮上的间隔即算法预估的下次 due，所见即所得。

纯翻面 · 零成本

看引子主动回忆 → 翻面看答案 → 自评四档。全程离线、无 LLM 调用，省电省流量，适合每天快速清队列。

掌握度标签 = 派生展示

薄弱/学习中/已掌握从 S 派生（S<1天→薄弱，>21天→已掌握）。set_mastery 与 AI 仍可手动覆盖，但调度依据是 S 与 due，不是标签。
