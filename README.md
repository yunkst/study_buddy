# 时习

**学而时习之，不亦说乎。**

一个把「苏格拉底式学习」与「遗忘曲线」做成日常习惯的学习 App。

## 为什么是「时习」

两千多年前，孔子说「学而时习之」—— 学过之后，在**恰当的时机**再去温习，才能真正记住、真正领悟。

这句话恰好道出了两件事：

- **什么时候该复习？** —— 在你快要忘、但还没忘的时候。这是科学，叫**遗忘曲线**。
- **怎么才算学懂了？** —— 不是被告知答案，而是被一步步问到自己想通。这是哲学，叫**苏格拉底学习法**。

时习做的事情，就是把这两条古老的智慧，变成你手机里每天打开就能用的工具。下面分别讲讲它们，以及时习如何落地。

---

## 🧠 苏格拉底学习法：被问到懂，而不是被告知懂

苏格拉底从不直接给学生答案。他只是提问 —— 一个接一个，顺着你的回答往下走，直到你自己把道理想通。两千多年过去，这种「问答式启发」依然是公认最深入、最不容易忘的学习方式。

为什么有效？

- **被动听懂 ≠ 真懂。** 听人讲一遍，你只是「认识了这个说法」；自己推一遍，它才真正长进脑子里。
- **问题会暴露你不知道什么。** 一个自己以为懂了的概念，被追问三句就露馅 —— 这恰恰是学习的起点。
- **想通的答案，记得最牢。** 自己走完的推理链路，远比被塞进脑子的结论难遗忘。

可现实里，很少有人愿意当你专属的「苏格拉底」。绝大多数老师、辅导书、网课，都会图省事直接把答案端给你。

**时习让 AI 来当这个提问者。**

在每一个知识点的详情页，都有一枚「**为什么？**」按钮。点进去，AI 不会立刻告诉你结论，而是从一个具体场景出发，反问你、引导你、顺着你已有的理解一步步推进。你卡住了，它给你一点提示；你跑偏了，它轻轻把你拉回来。直到你自己把那个「啊哈」时刻说出来。

它的耐心是无限的，它的追问也不会停在一个让你尴尬的地方。

> 这不是「更聪明的搜题」，而是「更耐心的陪练」。

## 📉 遗忘曲线：在该复习的时候复习

1885 年，心理学家艾宾浩斯用自己做实验，画出了一条著名的曲线 —— **遗忘曲线**：刚学完的内容，几小时内就开始快速遗忘，一天后可能只剩三分之一，随后遗忘才慢慢变缓。

```
记住的比例
100% ┤■
     ┤ ■
     ┤  ■
 50% ┤   ■■■
     ┤       ■■■
     ┤           ■■■■■■■■■■■■
  0% └──────────────────────────→ 时间
     刚学完   1天后    1周后
```

这条曲线告诉我们两件事：

- **复习不是越多越好，而是越准越好。** 在遗忘刚要发生的那个临界点复习一次，记忆就会被「重置」并加固，下一次撑得更久。
- **错过时机就是浪费。** 太早复习是重复劳动，太晚复习等于重新学一遍。

时习替你算好这个时机。我们采用遗忘曲线**更现代、更精确的版本——FSRS**（Free Spaced Repetition Scheduler）。它会为你的每一个知识点维护一个「记忆稳定性」数值：你答得越准、越轻松，它就越放心地把下次复习往后排；你犹豫了、忘了，它就赶紧把你拉回来。你只需要做一件事 —— **每天打开时习，把今天到期的那几张卡复习掉**。

> 不刷 100 张，只复习该复习的几张。少而准，才是符合大脑规律的方式。

## ✨ 时习帮你做的事

苏格拉底法和遗忘曲线是骨架，下面是长在骨架上的血肉：

| | 你能做的 |
|---|---|
| 📷 **拍题问 AI** | 拍一道题、选一张图，或直接打字提问。AI 帮你拆思路、给解析，还能把涉及的知识点自动整理进你的知识库。 |
| 🗂 **知识点库** | 按学科分类沉淀你学过的每个知识点，附「引子—答案—关联」，一眼看清自己学过什么、还差什么。 |
| 🎯 **间隔复习** | 每天只复习到期的几张卡，四档自评（忘了 / 困难 / 良好 / 简单），FSRS 自动排下次时间。 |
| ❓ **「为什么？」启发式教学** | 任意知识点点一下，AI 用提问带你从场景走到底层，想通了才算懂。 |
| 📅 **备考拆里程碑** | 告诉时习考试日期与目标，它帮你把漫长的备考期拆成一个个可执行的节点。 |
| ⏱ **专注时钟 + 学习日报** | 一键开始专注，结束自动汇总成当天的学习日报。学了多久、学了什么，一目了然。 |

## 🎨 一点美学坚持

时习不长成「又一个冷冰冰的工具」的样子。它有**纸感学术风**：米白纸纹的底色、朱砂红的印章、衬线体的大标题、像贴在笔记本上的拍立得照片、可以分享到小红书的手账日记卡。

我们觉得，学习本来就该是件有点郑重、有点温度的事。

## 👤 适合谁用

- **备考冲刺的同学** —— 考研、考公、考证、期末，需要一个能把长期记忆和复习节奏管起来的工具。
- **想真学懂、而不是只刷题的人** —— 愿意被「为什么？」追问，愿意自己把道理想通。
- **自带 AI 的重度学习者** —— 时习使用你需要自备的 AI 接口（在设置里填一次即可），你的提问全程走你信任的模型。
